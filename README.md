# NoAbsentQR
Say goodbye to wacky phone cameras when scanning for attendance!

## Features
- 📷 The ability to Scan Attendance QR Codes
- 💻 Open the link and register your Attendance
- 🔗 Share the Attendance Link if your friends can't scan it via Telegram
- ✅ Fully client-side. Zero backend servers

## Technical Information
- Built with vanilla JavaScript, HTML and CSS.
- No React.
- No Vercel.
- No backend servers.
- No unnecessary frameworks.
